Planejamento de publicação

Cenário atual

O projeto possui 10 páginas HTML na raiz, uma folha de estilos e imagens da logo. O único recurso multimídia incorporado é um mapa externo em Contato. Não existem vídeos ou áudios locais, scripts JavaScript, código PHP ou banco de dados nos arquivos atuais.

Os formulários apresentam campos de demonstração, sem processamento no servidor, armazenamento ou autenticação. O orçamento considera a publicação de arquivos estáticos em HTML e CSS. Não inclui implementação de cadastro ou agendamento real.

A página inicial é home.html. Será necessário configurar a entrada da hospedagem para esse arquivo; o teste de publicação ainda está pendente. A documentação acadêmica deve permanecer fora da publicação destinada aos clientes.

As unidades de limite não são equivalentes: tamanho do site, quantidade de arquivos e créditos de uso são critérios diferentes. Na Netlify, não se deve interpretar os créditos mensais como uma franquia exclusiva de transferência.

O GitHub Pages é uma alternativa para apresentação acadêmica. Suas regras restringem o uso como serviço gratuito para sites voltados principalmente a transações comerciais; a publicação de um serviço real de agendamento exigiria reavaliar essa alternativa.

Escolha proposta

A proposta é Cloudflare Pages Free com domínio .com.br no Registro.br. O site atual utiliza arquivos estáticos e pode ser publicado sem uma mensalidade de hospedagem. O HTTPS incluído e os limites de arquivos atendem ao porte acadêmico do projeto, enquanto a distribuição dos arquivos permite acomodar mais visitas sem modificar o HTML. A extensão .com.br é adequada ao público brasileiro. O custo de referência é R$ 40,00 por ano para o domínio, sujeito à confirmação da tarifa e da disponibilidade. Para demonstração, um subdomínio gratuito permite manter o custo em zero.

Essa escolha não implementa o envio dos formulários. Uma futura necessidade de processamento e armazenamento exigirá outra avaliação técnica e de custos. Vídeo e áudio, se adicionados posteriormente para a atividade, deverão ser avaliados quanto ao tamanho dos arquivos e à transferência; não são recursos existentes nesta versão.

Nenhuma hospedagem ou domínio foi contratado nesta tarefa. O grupo deve revisar as condições dos provedores antes de publicar.
